# acer-conquest-lsp-assets

This repository hosts public assets for the private `acer-conquest-lsp` Visual Studio extension repository.

Its primary purpose is to store files that must be publicly accessible when referenced from extension marketplace content, such as README images.

## Structure

- `images/` — screenshots, logos, and other image assets linked from the extension README or marketplace content

## Usage

Add public assets to this repository and reference them from the private extension repository using raw GitHub URLs or repository file URLs that are accessible without authentication.
